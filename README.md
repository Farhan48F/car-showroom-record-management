Car Showroom Record Management System

Project Description

The Car Showroom Record Management System is a Python-based console application designed to manage car records efficiently.

The application allows users to add, view, search, update, and delete car records. The records are stored permanently in a JSON file.

Features

- Add new car records
- View all car records
- Search cars by ID, brand, or model
- Update existing car records
- Delete car records
- Validate user input
- Handle exceptions
- Store records using JSON file handling
- Menu-driven console interface

Technologies Used

- Python
- JSON
- File Handling
- Exception Handling

Python Concepts Used

- Variables and Data Types
- Conditional Statements
- Loops
- Functions
- Exception Handling
- File I/O
- JSON
- CRUD Operations
- Menu-driven Application

Car Record Details

Each car record contains:

- Car ID
- Brand
- Model
- Price
- Stock Quantity

How to Run

1. Download or clone this repository.
2. Open the project folder in Python IDLE, VS Code, or another Python IDE.
3. Run:

python car_showroom.py

4. Select an option from the menu.

Menu

1. Add Car
2. View Cars
3. Search Car
4. Update Car
5. Delete Car
6. Exit
